# AI-generated voice source archive / AI 配音源音轨

这里只留存项目已经人工选定、非临时的 AI 生成音轨源文件，不是安装包。首批归档 160 个不同 WAV，对应 RA2/YR 的 244 个用音位置；另有 21 个同类已选位置尚未找到对应源 WAV，未以其他版本填补。

- manifest.json 用 game / kind / uid 映射游戏位置，sha256 标识文件内容，model 标注生成模型。
- 文件位置是 wav/<SHA256 前两位>/<完整 SHA256>.wav。同一段音频跨游戏复用时仅存一份。替换音轨时，先核对获选状态和来源，添加新哈希，再更新对应位置；不要覆盖已有哈希文件。
- 仅收录能映射到已核验候选记录、且 SHA256 与原版音频记录无重合的已选源音轨。不要把原版语音、参考音轨、训练素材、模型、审听数据库、淘汰或待审样本、混合 BAG/MIX 上传到这里。
- 本目录不参与安装包构建，也不替换现有 _src_files、assets/voice-manifest.json 或 voice/selected-lines.json。不要从游戏包抽取音频补齐这里的源文件。
- 本目录记录项目来源，不对素材或模型授予额外许可。
